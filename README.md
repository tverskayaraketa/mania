# ЦенгтроMania Telegram Review Bot

Бот для сбора отзывов о магазине iStore. Написан на Python и разворачивается через Railway.

## 📦 Установка

1. Форкни или склонируй этот репозиторий.
2. Перейди на [https://railway.app](https://railway.app) и создай проект:
   - Выбери "Deploy from GitHub"
   - Укажи этот репозиторий

## 🔐 Переменные окружения

Добавь переменные в Railway:

- `BOT_TOKEN` — токен от @BotFather
- `ADMIN_ID` — твой Telegram user ID (можно узнать через @userinfobot)
